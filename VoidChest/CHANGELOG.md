# 0.5.1

* 包名（GUID）统一为 `trigger.valheim.voidchest`（旧配置自动迁移）
* 物品描述改为功能说明（英文优先，三语保留）
* README 改为英文优先（英文 + 简体中文 + 繁體中文）

# 0.5.0

* 新增：远程存入支持联机客户端（专用服务器 / 联机主机）——不再仅限主机使用
  - 客户端把按本地规则过滤后的背包快照通过自定义 RPC 发送给服务端；
  - 服务端沿用原扫描/堆叠流程处理快照，回传实际移动差异（物品标识 + 数量）；
  - 客户端按差异从实时背包精确扣除，避免并发变动导致误删/复制；
  - 需要**服务端与客户端安装相同版本的本 mod**；服务端未安装时 30 秒后提示
* 变更：扫描缓存按玩家作用域隔离（不同玩家的守护石权限不同）
* 新增：服务端禁用远程存入时向客户端返回明确提示

# 0.4.0

* 新增：每级容量可配置（行/列，1-8）
* 新增：每级重量上限可配置（默认 100/150/300/800，0 = 无限制）
* 新增：重量显示为"当前/上限"
* 新增：手动存入（拖拽 / Shift 快速移动）超重时自动分堆，重量已满时无反应；附近/远程存储不受重量限制
* 新增：远程存储解锁机制（`RemoteStore.AlwaysAvailable`，默认关闭 = 装备魔能/L2 及以上宝箱解锁）
* 变更：界面合并为单按钮（未解锁显示"附近存储"，解锁后显示"远程存入"）
* 新增：物品描述（北欧魔法风格）
* 新增：三语言本地化（English / 简体中文 / 繁體中文）
* 新增：仓库与发布文件（README / manifest / icon / LICENSE）

# 0.3.2
